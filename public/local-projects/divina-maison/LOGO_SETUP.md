# Logo Setup Instructions

## Required Logo Files

Place the following logo files in the `images/` directory:

1. **logo-with-text.jpg** - Full logo with text (recommended size: 200x50px or similar aspect ratio)
2. **logo-icon.png** - Icon-only version (recommended size: 40x40px or similar)

## File Locations

```
DivinaMaison/
└── images/
    ├── logo-with-text.jpg
    └── logo-icon.png
```

## Current Implementation

The navigation currently uses `logo-with-text.jpg`. If the image files are not found, the site will fall back to displaying "DIVINA MAISON" as text.

## How to Update

1. Create an `images/` folder in the root directory
2. Add your logo files with the exact names above
3. The site will automatically use them

## Alternative: Use Text Logo Only

If you prefer to use only text (no images), the current setup will display "DIVINA MAISON" automatically when images are not found.
